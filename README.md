# Sales-Analysis-Dashboard
Sales Analysis Dashboard 📊

##Project Overview

This project analyzes sales and profit performance using Microsoft Excel. The interactive dashboard helps users explore sales across different product categories and regions.

*Tools Used*

Microsoft Excel

PivotTables and PivotCharts

Slicers

GETPIVOTDATA

Key Features

Sales and profit KPI cards

Category-wise sales analysis

Sub-category sales analysis

Interactive category and region filters

Dynamic dashboard for exploring sales performance

##Business Objective

To understand sales performance, identify profitable product categories, and compare results across regions to support data-driven decisions.

##Skills Demonstrated

Data cleaning, data analysis, dashboard development, data visualization, and reporting.
